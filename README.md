## About

I design, build and deploy AI systems end to end. My work sits where LLMs meet real business workflows: support bots that answer from a company's own documents, voice agents that book appointments, and automations that replace hours of manual effort.

I focus on the unglamorous parts that make AI usable in production: retrieval quality, agent orchestration, API integrations, deployment, and code the client can own and maintain.

**Problems I solve**

- Answering customer and staff questions accurately from private documents (RAG, GraphRAG, hybrid vector search)
- Automating multi-step operational work with agents and workflows
- Adding real-time voice and multimodal interfaces to existing products
- Taking AI prototypes through to deployed, documented software
